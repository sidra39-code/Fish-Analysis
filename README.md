# Fish-Analysis
Project Overview

This project analyzes fish growth performance and feed utilization under three experimental treatments (T0, T1, and T2). Statistical analysis was performed using R to compare treatment effects on growth and feed efficiency parameters.

Parameters Analyzed
Weight Gain: Evaluates changes in fish body weight across treatments.
Length Gain: Measures changes in fish length across treatments.
Specific Growth Rate (SGR %): Evaluates the daily growth performance of fish as a percentage.
Feed Conversion Ratio (FCR): Assesses feed utilization efficiency. A lower FCR generally indicates better feed efficiency.
Experimental Design

The dataset includes three treatments:

T0: Control treatment
T1: Experimental treatment 1
T2: Experimental treatment 2

Each treatment contains three replicates (n = 3).

Statistical Analysis

The following statistical methods were applied using R:

Mean and Standard Error (SE) calculations
One-way Analysis of Variance (ANOVA)
Tukey's Honest Significant Difference (HSD) post-hoc test for pairwise treatment comparisons
Graphical visualization of treatment means, standard error bars, and individual replicate observations

A significance level of p < 0.05 can be used to assess statistical significance.

Data Visualization

Colourful graphs were generated to compare Weight Gain, Length Gain, SGR, and FCR among the three treatments. The graphs display treatment means, standard error bars, and individual replicate values.
